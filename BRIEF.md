## My MVP features (build these first, in this order)
1. The user can request explanations in simpler language if needed.
2. The user can ask for summaries of long texts or concepts.
3. The user can ask the AI to explain a school subject in detail.
4. The user can type in specific questions about their homework.
5. The user can request step-by-step guides for solving problems.
